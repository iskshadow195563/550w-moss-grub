# 验证记录

验证日期：2026-10-08（Asia/Shanghai）。

## 安装与恢复

在 WSL 的 Kali Linux 中，仅对临时目录运行模拟安装测试；测试副本将全部系统路径重定向至临时文件系统。没有对 WSL 或电脑的真实 `/boot`、`/etc/default/grub`、EFI 分区执行安装。GRUB 工具与 QEMU 从发行版软件包解包到临时工具目录，没有安装系统软件包。

`tests/test_install.py` 的 14 个用例全部通过，使用真实的 `grub-script-check` 验证测试生成的 GRUB 配置：

- 默认安装保留默认系统设置与 Windows / Linux 启动项。
- 预检查与非法参数不写入系统。
- 生成失败、语法错误、主题缺失、Windows 入口丢失或 Linux 入口丢失时恢复原配置。
- 独立 `/boot` 分区使用的 GRUB 相对路径通过检查。
- 拒绝覆盖非本包管理的主题。
- 重复安装可切换布局；升级失败恢复上一版主题与配置。
- 卸载按当前内核重新生成配置；卸载失败恢复主题设置。

所有 Bash 脚本通过 `bash -n`。`tests/check_assets.py` 检查 PF2 真实字体名称、常用汉字与标点覆盖、五个主题文件的字体和九宫格素材引用，全部通过。

## 真实 GRUB 预览

预览通过 QEMU 11.1 的软件模拟、SeaBIOS 和 GNU GRUB 2.14-2+kali1 运行。虚拟机仅挂载本项目演示 ISO，不挂载真实硬盘。截图直接来自 GRUB 图形输出，并不是网页或概念图。

通过 QMP 键盘事件验证主菜单选择、中文高级选项子菜单、长子菜单滚动、Esc 返回与 C 命令行。截图位于本目录的 `preview-分辨率-场景.png`。演示菜单倒计时设为 30 秒以便截图；正式安装默认为 8 秒。

720p、1080p、1440p 和 4K 的预览实际输出分别为 1280×720、1920×1080、2560×1440、3840×2160。预览脚本明确设置与布局匹配的 `gfxterm_font`，避免一次加载所有字体后 GRUB 自动选择大字号导致低分辨率无法初始化图形终端。显示模式是否在用户电脑上可用，仍以该电脑固件为准。

`tests/check_captures.py` 对四种分辨率的真实截图检查了实际像素尺寸、红色高亮从 Ubuntu 移到 Windows、倒计时区域变化与子菜单滚动，全部通过。

## 验证范围

预览中的 Windows / Ubuntu 条目只显示演示文本，不启动操作系统。本次未在用户电脑的实际 Ubuntu 上安装主题、重启或验证两个系统的真实启动；也没有测试用户固件的 4K 图形模式、Secure Boot 或磁盘加密环境。主题包只使用原有系统入口，并在实际安装时重新检查配置。

背景实际像素尺寸为 1672×941，4K 主题布局会将其缩放。源参考图的 3840×2160 像素版本保存在项目源码的 `assets` 文件夹。

## 2026-10-23：跨电脑显示兼容修订

用户报告：通过原安装脚本安装后，同一次开机内等待或切换选项，菜单突然变成只显示一个很大的图标，但仍能切换。仅凭照片无法确定那台电脑的实际图形模式；本次没有连接或重启该电脑。

修订内容：新增 `--safe-mode` 紧凑布局，24 像素图标、32 像素行高、4 像素边框切片。只安装所选布局需要的字体和 CJK 14 控制台字体。在 `/etc/grub.d/00_550w_moss_font` 输出 `set gfxterm_font="MOSS CJK Regular 14"` 与 `export gfxterm_font`，该脚本按名称排序在 `00_header` 前运行。新增脚本与主题、配置片段一并参与升级、失败恢复及卸载。

- 使用 Ubuntu 官方 `grub-common` / `grub-pc-bin` 2.12-1ubuntu7.3 的实际 GRUB 模块，在无真实硬盘的 QEMU / SeaBIOS 虚拟机中检查。
- 1920×1080 下检查等待、连续切换 12 次、C 命令行与 Esc 返回，以及退出演示启动项回到菜单，布局正常。没有复现用户所述的完整突变触发过程。
- 强制 640×480 检查安全布局的同样流程；四个启动项的图标保持同时可见，选中框没有撑满菜单。截图为 `compat-640-initial.png`、`compat-640-switched.png`、`compat-640-returned.png`、`compat-640-entry-returned.png`。
- `tests/check_captures.py` 对上述四张低分辨率截图检查真实像素尺寸、四行图标可见性和选中区域高度，避免只凭画面有变化判断通过。
- 安装事务测试由 14 项增加到 17 项，全部通过：新增安全模式字体隔离、生成配置遗漏字体锁时回滚，以及拒绝覆盖非本包字体脚本。原有升级失败和卸载失败用例也检查字体脚本恢复。
- 字体与所有主题素材引用检查、Bash 语法检查，以及最终 ZIP 字节、LF 换行、可执行权限和完整性检查均通过。

这是对已确认的字体选择与低分辨率布局风险的加固，以及可验证的安全模式；尚不能据此声称已定位或彻底修复用户电脑上特定固件／GRUB 环境的触发原因。该电脑仍需实际安装修订包确认。UEFI、Secure Boot 及真实系统启动不在本轮虚拟机验证范围内。
